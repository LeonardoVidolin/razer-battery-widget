## Razer Battery Widget v1.1.0

### Added

- **Windows audio:** output (headphones) and microphone volume controls.
- **Always on top** (tray option), with stronger behavior on Windows.
- More reliable **battery** updates (app-side polling + more robust Synapse 3/4 parsing).

### Fixed

- **Synapse 3:** alternate parsing and fewer incorrect 0% readings on wireless headsets.
- **Synapse 4:** battery level as string, systray logs, and deduplication by device name.

### Install

Download **Razer Battery Widget Setup 1.1.0.exe** attached to this release. Razer Synapse 3 or 4 must be running for battery data.

See `CHANGELOG.md` in the repository for full details.
