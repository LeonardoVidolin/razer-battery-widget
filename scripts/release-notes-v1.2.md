## Razer Battery Widget v1.2.0

### Highlights

- **Resizable widget** — Frameless window with edge/corner resize; size and position are remembered.
- **Volume section toggle** — Collapse the sliders from the divider; audio keeps working.
- **Compact mode** — Smaller rings and text when the window is tiny; battery % remains readable.
- **Easier Windows builds** — Optional output folders when `dist/` is locked; signing disabled for local packaging.

### Requirements

Windows 10/11 and **Razer Synapse 3 or 4** running (same as before).

### Install

Download **Razer Battery Widget Setup 1.2.0.exe** from this release. Run the installer; Synapse must be running for battery data.
