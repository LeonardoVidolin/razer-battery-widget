### Fixed
- **Choppy dragging**: dragging the widget used to stutter every couple of seconds. The cause was a slow volume check that froze the app each time it ran. Volume reads are now near-instant and never block the app. They also pause while the volume panel is closed or the widget is hidden, so the app uses less CPU.

### Install
Download and run `Razer Battery Widget Setup 1.6.1.exe` below. It updates your current install in place and keeps your settings.
