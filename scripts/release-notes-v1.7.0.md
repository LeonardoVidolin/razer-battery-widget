### Added
- **Warning when Synapse isn't sending battery data**: sometimes Razer Synapse starts stuck waiting on an update and reports nothing until you open it. If no devices show up about 45 seconds after the widget starts, it now shows a warning with an **Open Synapse** button. You also get a Windows notification, and the tray icon tooltip changes. Opening Synapse lets it finish the update, and the batteries come back on their own. The warning shows at most once each time the widget starts, so it never spams you.

### Install
Download and run `Razer Battery Widget Setup 1.7.0.exe` below. It updates your current install in place and keeps your settings.
